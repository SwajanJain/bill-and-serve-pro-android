# Billit Owner Quick Guide (Non-Technical)

This guide is for daily use. No technical setup needed.

## 1) Open the system

- On laptop/desktop browser, open:  
  `http://<your-server-ip>:3001`
- On waiter phone, open the Billit app and login with PIN.

## 2) Daily workflow

1. Waiter selects table and adds items.
2. Waiter taps **Send to Kitchen**.
3. If same table orders again, waiter opens the same table and adds more items.
4. Cashier opens table on desktop, checks items, and does billing/payment.
5. After payment, table becomes free.

## 3) If internet/Wi-Fi is weak

- Waiter can keep taking orders.
- App will sync automatically when connection returns.
- If needed, go to Settings and tap **Retry Sync**.

## 4) If you see “Order locked”

- Ask manager/owner to open **Settings → Sync Conflicts**.
- Tap **Force Unlock** (only if required), then **Retry**.

## 5) Backup safety (Owner only)

- Open **Settings → Backups**.
- Tap **Create Backup Now** once daily (recommended end of day).

## 6) If something looks wrong

Do these in order:

1. Close and reopen app/browser.
2. Check Wi-Fi on device.
3. On phone login screen, tap **Server** and verify server URL.
4. Call support person.
